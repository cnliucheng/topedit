## 让编辑器回归极简

### 名称（Name）

`Topeditor`

### 副标题（Subtitle）

`轻量高效的代码与文本编辑器`

### 关键词（Keywords）

`代码编辑器,文本编辑,开发工具,Markdown,Git,多语言,轻量,效率`

### 描述（Description）

`Topeditor 是一款面向开发者与内容创作者的 macOS 编辑器，专注于快速打开、编辑与管理代码和文本文件。`

`核心能力：`
`- 项目/文件双模式打开，侧边栏管理清晰直观`
`- 支持 Swift、JSON、YAML、Markdown 等常见格式`
`- 内置 Git 工作流：状态查看、提交、分支、stash`
`- 设置可配置自动刷新与提交后自动推送`
`- 支持设置导入导出，便于多设备保持一致体验`

`Topeditor 强调轻量、直接、可控的编辑体验，帮助你在日常开发与内容编辑中更快进入工作状态。`
